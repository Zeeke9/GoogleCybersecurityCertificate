# 📘 Google Cybersecurity Professional Certificate Projects

This repository showcases key projects and case studies completed during the [Google Cybersecurity Professional Certificate](https://grow.google/certificates/cybersecurity/). It focuses on core security concepts, hands-on labs, and best practices aligned with real-world scenarios.

## 📚 Learning Outcomes
- Security Foundations & Risk Management
- Network Defense & Detection
- Security Policies & Controls
- Incident Handling
- Cybersecurity Career Prep

## 🛠️ Tools & Skills Applied
- Wireshark  
- Linux Command Line  
- SIEM basics (e.g., Splunk simulated environments)  
- Risk Assessment Templates  
- Phishing & Threat Response Walkthroughs
